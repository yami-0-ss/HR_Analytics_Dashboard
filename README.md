# 👥 HR Analytics Dashboard

An interactive **Power BI** dashboard that analyzes workforce data for **1,470 employees**, giving HR teams a clear view of headcount, attrition, and the factors that shape employee behavior across the organization.

---

## 🎯 Project Objective

HR teams need quick answers to questions like *"Who is leaving, and why?"* This dashboard helps to:

- Monitor key **workforce KPIs** in one place
- Analyze **attrition** across departments, job roles, and employee groups
- Explore how factors like **age, tenure, salary, and satisfaction** relate to employee outcomes
- Support **data-driven HR decisions** with interactive filtering

## 🛠️ Tools & Skills Used

- **Power BI Desktop**: data modeling, visuals, and interactivity

- **Data Visualization**: KPI cards, charts, slicers, and filters
